# 🃏 FlipMind

> **Remember anything without brute force.**  
> FlipMind is an offline-first, mathematical spaced repetition system engineered for technical learners, developers, and researchers.

## 🔬 Core Methodology

* **Memory Stability Scheduling:** Dynamic calculation of retention decay curves ($R(t) = e^{-\ln(9) \cdot t/S}$) rather than fixed arbitrary multipliers.
* **Leech Isolation:** Automatic detection and quarantining of cards causing high lapse ratios to preserve focus.
* **100% Offline-First Architecture:** Atomic file write-rename persistence ensuring zero data corruption without requiring cloud servers or mandatory accounts.
* **Monospace & Code First:** First-class syntax blocks and formatting for technical and algorithmic study.
