## ✨ Key Features

* 🧠 **Mathematical Spaced Repetition:** Dynamic memory stability algorithms calculate exact review curves so you study right before forgetting.
* 🃏 **Smooth 3D Perspective Flip:** 60fps 3D card flips with native Tinder-style swipe gestures for rapid thumb-friendly studying.
* 🔒 **100% Offline & Private:** Zero accounts required. No cloud tracking. Your learning decks and streak progress are stored locally on your device.
* ⚡ **2-Minute Blitz Mode:** Short on time? Review your highest priority 5 cards to preserve your streak.
* 🎯 **Leech Detection:** Cards that cause repeated lapses are automatically flagged with suggestions to split them into simpler concepts.
* 💻 **Code & Monospace Support:** First-class syntax blocks for programming languages with one-click copy and clean monospace typography.

## 🛠️ Architecture

* **Framework:** Flutter & Dart
* **Engine:** FSRS / SM-2 Spaced Repetition Algorithm
* **Persistence:** Offline-First Atomic Local Storage Engine
* **CI/CD:** Automated cloud compilation via GitHub Actions
